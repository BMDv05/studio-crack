Studio line-art tracer

Development tool. Turns the studio photograph into organized architectural line work — straight structural lines first, then boundaries, openings, furniture silhouettes and detail — and exports studio.lines.svg whose viewBox equals the photograph's pixel dimensions, so the drawing stays aligned with the image at every viewport size. This is a first pass: review it, tune the controls, and refine the result before shipping.
